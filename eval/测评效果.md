# Memory Agent 测评效果对比与分析

> 数据集：LongMemEval `longmemeval_s_cleaned`（500 题）
> 答题模型：glm-5.2
> Judge：glm-5.2（非官方 GPT-4o，三组同 judge 同数据，可横向比较，**不可**与 LongMemEval 论文官方分数直接比）
> 生成日期：2026-08-25

## 1. 实验配置

三组对照，隔离"提取"与"召回截断"两个变量：

| 组 | 提取 | 召回策略 | concurrency | 脚本 |
|----|------|----------|-------------|------|
| **A2** | memory agent 提取（v2 事实单元 prompt + 新喂法）| **ALL**（全部提取记忆灌给 reader）| 2 | `_run_a2_conc2.sh` |
| **A8** | memory agent 提取（同 A2）| **top_k=8**（只给 top-8 召回）| 8 | `_run_a8.sh` |
| **B**  | 不提取，原文直写 | Qdrant dense+bm25 RRF，top_k≈8 | — | `_run_s_full_3dir.sh` |

变量隔离关系：

- **A2 vs A8** = 固定提取，只变召回（ALL vs top_k=8）→ 隔离"召回截断"的影响
- **A8 vs B** = 固定 top_k=8，只变提取 vs 原文 → 隔离"提取"的影响

## 4. 分析

### 4.1 A2（提取 + 全量召回）全面最优

6 个类别里 5 个第一，overall 0.528 / task-avg 0.5547，且**拒答准确率 1.0**（不确定时完美拒答而非乱猜）。说明：**memory agent 的提取价值只有在全量召回时才充分释放**——把所有提取出的事实单元都给 reader，它才能跨会话聚合、做时序推理、比对偏好。

### 4.2 top_k=8 截断（A8）大幅拉胯，且几乎不比原文（B）强

A8 overall 0.368，task-avg 0.4174，**甚至略低于 B（0.4553）**。即：

- 召回从 ALL 砍到 top_k=8，丢掉了 16pp 的 overall accuracy；
- 一旦做了这种激进截断，"提取 vs 原文"的差别几乎被抹平（A8 ≈ B 甚至更差）。

**激进截断让提取的价值归零。**

### 4.3 唯一例外：single-session-assistant

这是 A8 唯一赢 A2 的类别（0.8929 vs 0.3929），且与 B 持平（0.875）。原因：这类题答案就在**最近一次会话**里，全量召回会把大量更早的记忆灌进来当噪音，反而干扰 reader；top_k=8 聚焦最近最相关 → 大幅提升。

**对"近期单会话"题，少即是多。**

### 4.4 需要广召回的类别被 top_k=8 摧毁

| 类别 | A2 → A8 | 跌幅 | 原因 |
|------|---------|------|------|
| multi-session | 0.5489 → 0.1805 | -37pp | 需跨多会话聚合，截断直接丢掉关键会话 |
| single-session-preference | 0.6333 → 0.1667 | -47pp | 偏好需回溯用户历史全貌 |
| temporal-reasoning | 0.3534 → 0.1955 | -16pp | 时序推理需沿时间线铺开记忆，top_k=8 拉不出足够时间跨度 |

### 4.5 模式总结：召回宽度应随题型而变

| 题型特征 | 适合召回策略 | 表现 |
|----------|--------------|------|
| 近期单会话、答案集中 | **小 top_k**（聚焦）| A8 胜 |
| 跨会话聚合、时序、偏好、知识更新 | **全量召回** | A2 胜 |

## 5. 结论与建议

1. **当前最优配置是 A2（提取 + 全量召回）**，建议作为基线保留。
2. top_k=8 这种定长截断**不可取**——在 5/6 类别上掉点，且抹平了提取的增益。
3. 若要兼顾 single-session-assistant（A8 强）与其余（A2 强），方向是**自适应召回**：按查询类型动态决定召回宽度——单会话近期题用小 top_k，跨会话/时序/偏好题放宽召回甚至全量。可用查询路由（query type classifier）或在 reader 侧做 memory 去重 + 时序保序来解决"全量灌入带来噪音"的问题，而不是靠激进截断。
4. ⚠️ 三组 judge 均用 GLM-4.7-Flash（非官方 GPT-4o），**彼此可横向比**（同 judge、同数据），但**不能**和 LongMemEval 论文官方分数直接比。
